# Code of Conduct

This project adopts the **Contributor Covenant v2.1** as its code of conduct.

Read the full text here:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

## Enforcement

Instances of unacceptable behavior may be reported to the project maintainers
by opening a confidential issue or by emailing the address listed in
[`SECURITY.md`](SECURITY.md). All complaints will be reviewed and investigated
promptly and fairly.

Maintainers are obligated to respect the privacy and security of the reporter
of any incident.
